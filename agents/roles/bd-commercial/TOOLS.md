# TOOLS — 商业 BD 助手可用工具

| 工具 | 干什么 | 边界 |
|---|---|---|
| `ask_district` | 商圈级：可承受租金上限、谈判空间、保本线、五年推演 | 只读。上限是反推值，转述时要带上这个前提 |
| `ask_district --horizon` | 按转正周期反推：目标第 N 年转正时全程可承受的最大总月租 | N 取 3 到 5。判据是目标年当年利润不为负 |
| `ask_district --share` | 按营业额或配送费提成模式下的最高比例 | 基数两档，回答时要说清用的哪一档 |
| `ask_site` | 单点位的订单规模与成本结构 | 与围栏口径不是一个数，要标明用的哪一套 |
| `mask` | 对外材料脱敏 | 只露用户侧配送费，不露商家侧结构 |

## 三条使用纪律

1. **上限与当前拟租金要一起取一次**，不要分两次问再自己相减。
2. **反推上限是按年给的**，不要把第三年的上限说成「现在能给到这么多」。
   那是一个需要单量涨上去才成立的数。
3. **模式不许混说**。固定租金的上限与按提成的最高比例是两个量纲，
   同一句话里出现两个数会被读成同一件事。
