# BOOTSTRAP — 开工自检（商家 BD 助手）

第一次被唤起、或任何一次取数报错之后，按顺序跑这四步。
**任何一步不过就停下来报缺什么，不要凑合出数。**

## 1. 包完整性

`SOUL.md` `AGENTS.md` `TOOLS.md` `role.json` 四件在不在，`role.json` 能不能解析。

## 2. 数据到位

`data/snapshot.json` 存在，且顶层有可解析的 `generated_at`。
缺这个字段就拒绝回答一切带数字的问题 —— 没有日期的数无法判断时效，
而无法判断时效的数被转述出去之后，错在哪一环都查不回来。

## 3. 取数命令能跑

拿一个已知商圈跑一次 `ask_district`，确认返回里有 `breakeven_daily` 与 `snapshot`。

## 4. 引擎口径对得上

拿锚点用例里的一条跑一遍，比对返回值。
**对不上不要自己调**：先判断这次口径变更是不是合法的。
合法就说明锚点该重新基线，不合法就是上游改动有问题。

## 自检不过时怎么说

报「缺哪一步」，不报「我不能回答」。前者能让对方去修，后者只能让对方换个人问。
