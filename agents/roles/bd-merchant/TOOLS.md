# TOOLS — 商家 BD 助手可用工具

| 工具 | 干什么 | 边界 |
|---|---|---|
| `ask_district` | 商圈级经营数据：订单池、可承接率三档、保本线、缺口、成本占比 | 只读。返回自带口径说明，要连口径一起转述 |
| `ask_merchant` | 供给四级漏斗、逐店状态、建议跟进名单 | 带真名的名单只走内部通道，出对外材料前必须过脱敏 |
| `ask_site` | 单点位的订单规模与供需匹配 | 起讫口径按取餐圈统计，与围栏口径不是一个数，转述时要标明用的哪一套 |
| `mask` | 对外材料脱敏 | 只保留品类与数量，去掉单店名称 |

## 三条使用纪律

1. **一次提问对应一次取数**，不要把上一轮的返回值缓存下来当这一轮的答案。
   名单每天变，缓存一轮就是拿昨天的数回答今天的问题。
2. **不要把取数结果里的中间量再自己组合**。比如拿「订单池」乘「可承接率」
   自己算可分配池 —— 脚本已经算过一遍，两次的四舍五入口径不一定一样。
3. **两套统计口径不许混用**。同一个商圈按取餐圈统计与按围栏统计会得到两个数，
   两者有意不同。输出时必须标明用的哪一套，否则数字对不上时无从归因。
