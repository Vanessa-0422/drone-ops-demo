# HEARTBEAT — 定期推送（默认关闭）

默认不推送。使用者明确开启后才启用。

## 为什么默认关

推送是打扰。一条没人看的日报，比没有日报更糟：
它让所有人以为「信息已经同步过了」，而实际上没有人读。
所以开启之前要先有一个具体的人、一个具体的场景。

## 开启后推什么

一周一条，只推**变化**，不推存量：

- 本周新签几家、新进动销几家
- 掉出动销的有哪几家（这一条比新增重要，它是流失信号）
- 高销品上架进度的周变化
- 距转正缺口的周变化

## 不推什么

- 不推全量名单。名单在工具页上，推送里放不下也不该放。
- 不推没有变化的指标。一条「本周无变化」的推送等于零信息，
  但它会让下一条真有变化的推送也被当成噪声跳过。
